## 🚀 Local Development

1. **Clone repository**:
   ```bash
   git clone https://github.com/VShaunak/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```

4. **Build production bundle**:
   ```bash
   npm run build
   ```

5. **Preview production build locally**:
   ```bash
   npm run preview
   ```

## 🚢 GitHub Pages Automated Deployment

The project is fully pre-configured for automated continuous deployment via **GitHub Actions** (`.github/workflows/deploy.yml`):

1. Commit and push your changes to branch `main`:
   ```bash
   git add .
   git commit -m "Deploy premium developer portfolio"
   git push origin main
   ```
2. Navigate to your GitHub repository: **Settings → Pages**.
3. Under **Build and deployment → Source**, select **GitHub Actions**.
4. The GitHub Actions runner will automatically build the static assets, copy the 404 handler, and publish the portfolio to:
   ```text
   https://vshaunak.github.io/Portfolio/
   ```

Relative asset paths (`base: './'`) ensure that the site works seamlessly whether served under a subdirectory (`/Portfolio/`) or on a custom apex root domain (`vshaunak.github.io`).
